# Carros.motos

Uma página web estática dedicada à apresentação de carros e motos. O catálogo reúne veículos variados em cartões com imagens, nomes e chamadas para ação.

## Tecnologias

- HTML5
- Bootstrap 5.0.2 (CSS e JavaScript carregados via CDN)

## Como visualizar

1. Clone ou baixe este repositório.
2. Abra `Carros.Com/index.html` em um navegador.

Não é necessário instalar dependências nem executar um servidor.

## Estrutura

```text
.
├── README.md
└── Carros.Com/
    └── index.html
```

## Observações

Este projeto é uma demonstração de interface estática. Os links e botões dos veículos ainda usam destinos de exemplo; não há, no momento, funcionalidades de compra, pesquisa ou integração com um backend.
